AstroPratidin Publisher

AstroPratidin Publisher is a private automation system used to prepare and publish AstroPratidin video content to the project's YouTube channel.

What the application does

The application uses Google's YouTube API to upload videos to the authorized AstroPratidin YouTube channel. Authorization is performed by the channel owner and is used only for this publishing workflow.

Google API data

The application requests YouTube upload authorization. OAuth credentials are stored as protected GitHub Actions secrets and are used by the automated publishing workflow. The application does not sell Google user data or use it for advertising.
