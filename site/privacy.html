Privacy Policy

Application: AstroPratidin Publisher

Effective date: September 9, 2026

1. Purpose

AstroPratidin Publisher is a private automation application used by the channel owner to prepare and publish AstroPratidin video content to YouTube.

2. Google API data we access

The application uses the YouTube Data API and requests authorization to upload videos to the authorized YouTube channel. Depending on Google's authorization response, OAuth tokens are used to maintain that authorization for the automated publishing workflow.

3. How Google data is used

Google API data is used solely to perform the requested YouTube publishing operation. It is not sold, rented, used for advertising, or used to build profiles about individuals.

4. Storage and security

OAuth credentials used by the automated workflow are stored as protected GitHub Actions secrets. They are not intentionally included in source code, generated videos, public web pages, or application logs.

5. Sharing and disclosure

Google API data is not shared with third parties except where necessary for the operation of the Google and GitHub services used by the publishing workflow, or where required by law.

6. Retention and deletion

OAuth credentials are retained only for as long as the channel owner requires automated publishing. The channel owner may revoke the application's Google authorization at any time through the Google Account security controls and may remove the corresponding GitHub Actions secret.

7. Cookies and tracking

The AstroPratidin Publisher website does not intentionally set advertising or analytics cookies and does not operate behavioral tracking.

8. Changes

This policy may be updated when the application's functionality or data practices change. The effective date above will be updated when material changes are made.

9. Contact

Privacy questions can be directed to the application owner through the support contact associated with the AstroPratidin Publisher OAuth application.
